# GitLab Duo Remote Prompt Injection (Legit Security, 2025)

Legit Security reported a remote [[prompt-injection]] vulnerability in **GitLab Duo**, GitLab's AI assistant. Cited by Invariant's [[github-mcp-private-repo-leak|GitHub MCP writeup]] ([[invariant-github-mcp-vulnerability]]) as evidence that injection-driven agent hijacking generalizes beyond GitHub MCP to other coding-assistant platforms, reinforcing that the class ([[toxic-agent-flow]], [[confused-deputy]]) is not vendor-specific.
